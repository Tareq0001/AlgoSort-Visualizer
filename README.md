# AlgoSort Visualizer 📊⚡

> An interactive, real-time sorting algorithm visualizer with sound synthesis and complexity benchmarks.

Developed by **Tareq Aboushi** ([@Tareq0001](https://github.com/Tareq0001)).

---

## 🌟 Features
- **5 Core Sorting Algorithms:**
  - Bubble Sort ($O(n^2)$)
  - Selection Sort ($O(n^2)$)
  - Insertion Sort ($O(n^2)$)
  - Quick Sort ($O(n \log n)$)
  - Merge Sort ($O(n \log n)$)
- **Interactive Controls:**
  - Play, Pause, Resume, and Step-by-Step execution via ES6 Generators.
  - Adjustable array size (10 to 75 elements).
  - Variable speed/delay slider (5ms to 300ms).
  - Multiple initial dataset patterns: Random, Nearly Sorted, Reversed, and Few Unique.
- **Audio Synthesis:**
  - Integrated Web Audio API oscillator emitting pitch frequencies mapped to array values during comparisons and swaps.
- **Real-Time Telemetry:**
  - Live comparison counter, swap/overwrite counter, and millisecond elapsed timer.
- **Bilingual Interface:**
  - Full Arabic and English support with fluid RTL/LTR typography.
- **Zero Dependencies:**
  - 100% pure vanilla JavaScript, HTML5 Canvas/DOM, and CSS3.
